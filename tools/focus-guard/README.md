# Focus Guard

就活中などに集中するための、Windows（Chrome / Edge）用サイトブロック拡張 + iPhone 設定手順。
ラーメンブログ本体とは無関係の独立したツールです（ビルド・デプロイには影響しません）。

## PC（Chrome / Edge）への入れ方

1. このフォルダ（`tools/focus-guard`）をPCに保存する（**入れた後は消さない・移動しない**。拡張がこのフォルダを参照します）
2. Chrome なら `chrome://extensions`、Edge なら `edge://extensions` を開く
3. 右上の「デベロッパー モード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選ぶ
5. 拡張アイコン（パズルピース）から Focus Guard を開き、サイト・時間帯を確認する

**普段使うブラウザ全部に入れてください**（Chrome と Edge 両方使うなら両方）。入れていないブラウザは素通りになります。

## 機能

- 指定サイト（サブドメイン含む）を開くとブロック画面に飛ばす
- 毎日の自動ブロック時間（曜日・開始/終了時刻。日またぎ可）
- 集中モード（今から 25/60/120/180 分。始めたら**短縮不可**、延長のみ可）
- 解除しにくい仕組み
  - ブロック中は、サイトの削除・時間帯の変更ができない（追加・延長は可）
  - ブロック中は `chrome://extensions` / `edge://extensions` を開けない（無効化・削除の衝動対策）
  - どうしても解除したいときは「解除チャレンジ」: 60 秒待つ → ランダムな 32 文字を**手入力**（貼り付け不可）→ 5 分間だけ解除

初期設定（編集可）: サイトは youtube.com / x.com / twitter.com / instagram.com / tiktok.com / netflix.com / nicovideo.jp / twitch.tv / reddit.com、時間帯は毎日 09:00〜21:00。

## 限界（正直に）

- 拡張なので、**インストールしていない別ブラウザ・シークレットウィンドウ（拡張を許可していない場合）・スマホ**は止められません。シークレットで使う場合は拡張の詳細で「シークレットでの実行を許可」をオンに。
- 拡張自体は、ブロックしていない時間帯なら削除できます。**ブロックしていない時間に消す衝動**まで止めたいときは、自動ブロック時間を長めにする、Windows の管理者権限を別の人に預ける、などの OS 側の対策が要ります。
- アプリ（Steam・Discord 等）はブロックできません。必要なら次の段階で Windows 常駐ツールを作ります。

## iPhone（アプリは自作せず、標準のスクリーンタイムを使う）

※以下は一般知識としての手順です（iOS のバージョンで文言は多少違います）。

iPhone は、他のアプリを止める機能を自作アプリで実現するのが Apple の審査・権限的に難しいため、標準機能を使うのが確実です。

1. 設定 → スクリーンタイム → 「スクリーンタイムをオンにする」
2. 「App使用時間の制限」→ 制限を追加 → SNS・動画・ゲームなどを選び、時間を短く設定
3. 「休止時間」で、作業・睡眠時間帯は許可したアプリ以外を使えなくする
4. 「スクリーンタイム・パスコードを使用」を設定する
   - **ここが一番大事**: 自分で決めた覚えやすい数字だと、衝動で解除できてしまいます。信頼できる人に決めてもらうか、ランダムな数字にして紙に書いて渡す、などで自力解除しにくくする
5. 設定 → スクリーンタイム → コンテンツとプライバシーの制限 で、Safari の Web サイトを制限することもできます
